# RQubo

RQubo es un equipo de tres desarrolladores que crea software a medida, sitios web y aplicaciones para simplificar procesos y ayudar a empresas y organizaciones a crecer.

## Formulario de contacto

Las consultas se envían a `rqubosoftware@gmail.com` mediante [FormSubmit](https://formsubmit.co/), compatible con sitios estáticos y GitHub Pages. El visitante ingresa su email para que RQubo pueda responderle directamente. Con JavaScript, el envío se realiza dentro de la página; sin JavaScript, se usa el envío HTML del servicio.

Antes de recibir consultas reales, enviar una consulta de prueba desde el sitio publicado y abrir el correo de activación de FormSubmit en `rqubosoftware@gmail.com` (revisar también Spam). Confirmar el enlace y enviar otra consulta para verificar la recepción. La activación se realiza una sola vez por formulario; si cambia el dominio, verificar nuevamente. No se necesitan claves ni contraseñas de Gmail en el sitio.

El formulario incluye un campo oculto contra bots, validación, estado de envío y mensajes de éxito o error. Solo se limpia después de que el servicio acepta el envío. Las consultas pasan por FormSubmit; su disponibilidad y límites dependen del servicio.
