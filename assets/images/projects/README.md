# Capturas de proyectos

Imágenes utilizadas en las cards de la sección «Proyectos en acción» de `index.html`.

- `proyectoConvenios.png`: captura proporcionada por el equipo del tablero de Relaciones Institucionales. Se conserva el archivo original, sin recortes.

Para añadir una captura, guardala en esta carpeta y agregá un enlace dentro de `.project-showcase-media` siguiendo las instrucciones del README principal. El nombre del archivo por sí solo no incorpora la imagen a la galería.
